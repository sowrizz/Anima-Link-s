# 1. Thought Monster Battle

This should be the **main signature game** of Anima-Link.

## What it solves

The user has a stressful thought, but instead of giving boring advice, the app turns the thought into a “monster” that can be defeated using CBT.

## When it starts

It starts from:

```txt
Chat message
Voice transcript
Mood Quest
Memory recall
Manual game launch
```

Example user says:

```txt
I’ll never finish this assignment. I always mess up before exams.
```

The AI detects:

```txt
Mood: High Stress
Absolutist words: never, always
Distortion: Overgeneralization
Trigger: Exam / assignment pressure
MSI: 82 · High Strain
```

Then the game begins.

## How we make the AI perfect

Use a strict JSON output, not random chatbot text.

Backend should return:

```json
{
  "monster_name": "Never-Finish Beast",
  "trigger_words": ["never", "always"],
  "distortion": "overgeneralization",
  "secondary_distortion": "all-or-nothing thinking",
  "emotion": "high stress",
  "msi_state": "High Strain",
  "cbt_question_1": "What is the monster trying to make you believe?",
  "cbt_question_2": "What evidence does not fully support this thought?",
  "memory_query": ["exam stress", "assignment", "never finish"],
  "recommended_next_action": "5-minute focus sprint",
  "safe_reframe": "I can start with one section."
}
```

AI quality rules:

```txt
Do not diagnose.
Do not overpromise.
Do not give generic reassurance.
Always identify the trigger phrase.
Always create one CBT question.
Always create one tiny action.
Always store thought → reframe pair.
```

This makes it feel professional and reliable.

This is the visual layer that makes progress feel alive.

## What it solves

Users usually cannot see emotional progress. This makes memory visible.

## Rooms

```txt
Storm Cave → stress moments
Focus Forest → focus wins
Mirror Lake → journal reflections
Boss Arena → completed battles
Proof Mountain → tiny wins
Breakthrough Gallery → reframes
Calm Garden → breathing/grounding
```

## What each artifact contains

Example:

```txt
Artifact: Reality Sword
Unlocked from: Thought Monster Battle
Original thought: “I’ll never finish.”
Reframe: “I can start with one section.”
Proof: Tiny Win Crystal
```

## AI role

AI organizes memories into rooms:

```json
{
  "memory_type": "reframe",
  "room": "Breakthrough Gallery",
  "artifact": "Reality Sword",
  "linked_trigger": "exam stress"
}
```

This is powered by vector DB tags.

# Game-to-AI Mapping

Use this table for implementation.

|Game|AI used|What AI does|
|---|---|---|
|Thought Monster Battle|Text AI + CBT classifier + memory search|Detects distortion, creates monster, asks CBT questions, stores reframe|
|Focus Boss Fight|Task parser + camera AI + memory|Converts goal into tiny steps, verifies proof, stores win|
|Room Transformation|Camera vision AI|Detects objects and maps them to game labels|
|Grounding Treasure Hunt|Camera vision AI|Finds target objects/colors and gives grounding prompts|
|Tiny Win Proof|Camera vision AI + memory|Detects proof and stores it as counter-evidence|
|Mood Quest|Voice AI + camera AI + routing AI|Detects current state and builds a short quest|
|CBT Response Arena|Text/voice AI scoring|Scores aggression, clarity, solution-focus, absolutist language|
|NPC Practice|Voice AI + roleplay AI + scoring|Simulates conversation and gives feedback|
|Voice Spell System|Speech-to-text + intent router|Routes commands to the right game|
|Memory Museum|Vector DB + summarizer AI|Turns stored events into artifacts and rooms|
