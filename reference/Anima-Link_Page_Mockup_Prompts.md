ANIMA-LINK
Detailed Mobile Page Mockup Prompt Document
For generating mature, premium mockups that Codex can use as the React Native / Expo visual reference
Design Positioning
Anima-Link should look like a premium mental-health and productivity companion, not a children's fantasy game. Keep the product mechanics powerful, but make the visual language mature: guided regulation, memory maps, progress proof, and support modes.


# How to Use This Document

Attach your reference images when asking ChatGPT/image generation for mockups.
Paste the Global Design System first, then paste one page-specific prompt.
Generate only the priority pages first: Home, Chat, Missions, Thought Challenge, Camera Grounding, Focus Session, Progress Proof, Memory Core, Memory Map, Support Modes, Privacy & Safety.
Give the resulting mockups to Codex as the visual system for all app screens.
Keep mature page names in mockup prompts even if the internal app uses fun names.

# Final Demo Flow These Screens Should Support

Home Dashboard shows elevated focus friction and suggested reset.
Chat Insight detects high stress, absolutist words, overgeneralization, and memory recall.
Support Modes recommends Ground -> Reframe -> Act.
Thought Challenge converts the stressful thought into a guided CBT reflection.
Camera Grounding scans the workspace and identifies distraction/focus objects.
Focus Session converts the goal into a 5-minute checklist.
Progress Proof stores one small completed action.
Memory Core shows the saved reframe and proof.
Memory Map visualizes the chain: Exam Stress -> Never thought -> Reframe -> Focus step -> Progress proof.
Weekly Reflection and Privacy & Safety prove clinical credibility, auditability, consent, and deterministic safety routing.

Core Visual Rule
Powerful backend, calm interface. The app can internally model thoughts as monsters and actions as proof, but the mockups should show mature language: thought patterns, guided challenges, focus sessions, progress proof, and memory maps.
